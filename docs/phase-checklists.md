# Phase checklists

`CLAUDE.md` Section 23 requires a checklist in the repository for each phase,
and forbids marking an item complete without evidence.

An item is checked only when the artifact it names exists in the repository, or
the command it names has been run and its output recorded. "Looks done" is not
evidence.
